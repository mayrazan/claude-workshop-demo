O que é Claude Code?

  • CLI oficial da Anthropic para desenvolvedores
  • Entende o contexto do projeto (arquivos, padrões, histórico)
  • Integra com ferramentas do dia-a-dia
  • Executa comandos, edita arquivos, cria PRs
  • Funciona dentro do VS Code ou terminal
