    Note: `@types/node` is already a devDependency.

    **Step 2 — Update `package.json` scripts:**
    Replace the `"scripts"` section with:
    ```json
    "scripts": {
      "dev": "concurrently \"npm run dev:server\" \"npm run dev:client\"",
      "dev:client": "vite",
      "dev:server": "tsx --watch server/index.ts",
      "build": "tsc -b && vite build",
      "lint": "eslint .",
      "preview": "vite preview"
    }
    ```

    **Step 3 — Update `vite.config.ts`** to add the /api proxy:
    ```typescript
    import { defineConfig } from 'vite'
    import react from '@vitejs/plugin-react'

    export default defineConfig({
      plugins: [react()],
      server: {
        proxy: {
          '/api': {
            target: 'http://localhost:3001',
            changeOrigin: true,
          },
        },
      },
    })
    ```

    **Step 4 — Update root `tsconfig.json`** to add server project reference:
    ```json
    {
      "files": [],
      "references": [
        { "path": "./tsconfig.app.json" },
        { "path": "./tsconfig.node.json" },
        { "path": "./server/tsconfig.json" }
      ]
    }
    ```

    **Step 5 — Create `server/tsconfig.json`:**
    ```json
    {
      "compilerOptions": {

        "module": "ESNext",

        "noUnusedLocals": true,
        "noUnusedParameters": true,
        "skipLibCheck": true,
        "outDir": "../dist-server",
        "rootDir": "."
      },
      "include": ["."]

    ```

<task type="auto">
  <name>Task 3: Create Express server entry point</name>
  <files>
    server/index.ts
  </files>
  <action>
    Create `server/index.ts`. This is the Express app entry point. It must:
    - Import `dotenv/config` as the FIRST import (before anything that reads process.env)
    - Use `express.json()` for body parsing (no body-parser package — it's built into Express 4.16+)
    - Mount the meetings router at `/api/meetings` (this router is created in Plan 02 — use a placeholder stub for now that returns 501 so the server is runnable)
    - Listen on `process.env.PORT || 3001`

    ```typescript
    import 'dotenv/config'
    import express from 'express'
    import { Router } from 'express'

    const app = express()
    const PORT = process.env.PORT ?? 3001

    app.use(express.json({ limit: '1mb' }))

    // Placeholder router — replaced by Plan 02
    const meetingsRouter = Router()
    meetingsRouter.post('/process', (_req, res) => {
      res.status(501).json({ error: 'Not yet implemented' })
    })

    app.use('/api/meetings', meetingsRouter)

    app.listen(PORT, () => {
      console.log(`Server running on http://localhost:${PORT}`)
    })
    ```

    Note: Do NOT import cors — the Vite proxy handles CORS in development. For MVP this is sufficient.
    Note: Do NOT use VITE_* for any env var in server/ files.
  </action>
